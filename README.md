#  DevOps Tools
> "Automate, integrate, and deliver better software! "
##  Git
![Git](https://img.shields.io/badge/Git-F05032?logo=git&logoColor=white)
### Purpose
Git is a **version control system** used to track changes in source code.
### Official Website
[Git Official Website](https://git-scm.com/)
### Common Command
```bash
git clone https://github.com/user/repository.git
```
## Docker
![Docker](https://img.shields.io/badge/Docker-2496ED?logo=docker&logoColor=white)
### Purpose
Docker is used to **build, run, and manage applications in containers**.
### Official Website
[Docker Official Website](https://www.docker.com/)
### Common Command
```bash
docker run hello-world
```
## Jenkins
![Jenkins](https://img.shields.io/badge/Jenkins-D24939?logo=jenkins&logoColor=white)
### Purpose
Jenkins is an automation server used for **Continuous Integration and Continuous Delivery**.
### Official Website
[Jenkins Official Website](https://www.jenkins.io/)
### Common Command
```bash
java -jar jenkins.war
```
## Kubernetes
![Kubernetes](https://img.shields.io/badge/Kubernetes-326CE5?logo=kubernetes&logoColor=w
hite)
### Purpose
Kubernetes is used to **deploy, manage, and scale containerized applications**.
### Official Website
[Kubernetes Official Website](https://kubernetes.io/)
### Common Command
```bash
kubectl get pods
```
## AWS
![AWS](https://img.shields.io/badge/AWS-232F3E?logo=amazonaws&logoColor=white)
### Purpose
AWS provides **cloud computing services** such as storage, databases, servers, and
networking.
### Official Website
[AWS Official Website](https://aws.amazon.com/) 
### Common Command 
```bash 
aws s3 ls 
```
